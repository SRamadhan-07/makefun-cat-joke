Competition: [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262)

## Run

```sh
python3 main.py
```

This writes the entry text (UTF-8, single line) to `/output/entry.txt`.
